مبنية بمبدأ واحد في كل قسم: افحص ← اشرح ← أصلح.

PHP و Node.js لكل حساب

إصدارات مثبّتة مركزيًا يختار كل حساب منها، ويعمل تطبيقه بهويته داخل حدوده — لا تداخل بين الحسابات.

أمان من التصميم

فصل صلاحيات، مستخدم لينكس وslice لكل حساب، SELinux، وفلترة صادر — المهاجم لا يخرج من موقعه.

نسخ خارج السيرفر

ارفع نسخك إلى MEGA أو تخزين متوافق مع S3 (Backblaze · Wasabi · R2) بنقرة — فالسيرفر المفقود ليس نسخة مفقودة.

DNS و بريد و SSL

PowerDNS للنطاقات، بريد عبر Postfix و Dovecot بمكافحة انتحال، وشهادات Let's Encrypt تتجدّد وحدها.

مدير ملفات و طرفية

مدير ملفات برفع وسحب، محرّر أكواد (Monaco)، وطرفية ويب تعمل بهوية الحساب داخل جلسة معزولة.

خفيفة وسريعة

ملف تنفيذي واحد بلغة Go، بلا أدوات بناء ثقيلة، يعمل على AlmaLinux / Rocky / RHEL — عربية وإنجليزية.

الأمان ليس إضافة — إنه الأساس

  • فصل الصلاحيات: وكيل مميّز معزول، وواجهة ويب بلا صلاحيات تطلب العمليات بالاسم فقط.
  • عزل لكل حساب: مستخدم لينكس وslice بحدود المعالج والذاكرة والعمليات، وحصّة قرص، وSELinux.
  • مركز حماية: يفحص تصلّب النظام، يشرح كل بند، ويُصلحه بنقرة — مع تراجع آمن.
  • مراقبة: كل دخول وكل أمر نُفِّذ، مع العنوان والبلد، محفوظة محليًا دون أي خدمة خارجية.

تنصيب بأمر واحد

شغّل الأمر على سيرفر AlmaLinux / Rocky / RHEL نظيف. ينزّل أحدث إصدار من القناة الرسمية، يتحقّق من بصمته، ويطبع رابط اللوحة وكلمة مرور لمرة واحدة.

install 
$ curl -fsSL https://aamrpr.github.io/adminserver-site/install.sh | sudo bash

# منفذ آخر: sudo PANEL_PORT=9443 bash  ·  نسيت كلمة المرور: sudo adminserver reset-password  ·  تحديث لاحق: بنقرة من داخل اللوحة.
